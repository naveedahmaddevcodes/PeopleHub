PeopleHub — HR Management System (HRMS)

PeopleHub is a full-stack HR management system that helps businesses manage employees, attendance, leave, and workforce data from one platform. Built with the MERN stack (MongoDB, Express.js, React.js, Node.js), it gives Admins, Managers, and Employees role-based access to handle onboarding, daily attendance, leave requests, and reporting.

Tech Stack
Frontend: React.js (Vite), Redux Toolkit, RTK Query, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB (Mongoose)
Auth: JWT (access + refresh tokens), bcrypt
File Storage: Cloudinary
